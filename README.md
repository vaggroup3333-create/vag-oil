# VAG Oil POS

Касса, товары, закупки, начальные остатки, долги и отчёты магазина. Приложение можно установить отдельной копией на собственном компьютере или сервере.

## Установка

**[Пошаговая инструкция на русском →](docs/INSTALL-RU.md)**

Нужны Node.js 22.13+ (ветка 22), pnpm 11.25.0 и Python 3.10+.

```sh
git clone https://github.com/vaggroup3333-create/vag-oil.git
cd vag-oil
pnpm install --frozen-lockfile
pnpm build
python3 scripts/setup-instance.py
pnpm start:local
```

В Windows вместо `python3` используйте `py -3`. Установщик попросит создать **свой новый логин и пароль**. Открыть на этом компьютере: `http://localhost:9088/vag-oil/`.

Для загрузки переданной владельцем базы укажите путь к приватному архиву при **первой** настройке:

```sh
python3 scripts/setup-instance.py "/path/to/VAG-Oil-private-database.zip"
```

Архив нужно получить у владельца лично. В публичном репозитории нет базы магазина, клиентов, продаж, долгов, фотографий товаров или паролей. Импорт создаёт отдельную копию; синхронизации с исходным магазином нет.

Для работы с телефонов и других компьютеров настройте HTTPS на своём домене по инструкции. Сервер приложения слушает только локальный адрес.

## Версия и данные

- Версия **0.67.0**: личные учётные записи кассиров. Директор добавляет сотрудников в разделе «Кассиры», задаёт логин и пароль, меняет или отключает доступ. В истории продаж доступны имя кассира, фильтр по сотруднику и переход к его чекам. Автор сохраняется в новых чеках, в том числе созданных без интернета; старые чеки без автора показывают «Не указан».
- Компактное окно выбора товаров, поиск на телефоне и карточки корзины. Меньше отступов, товары в окне выбора показаны строками.
- У каждого товара в корзине есть кнопки «Розница» и «Оптом». В одном чеке можно продавать разные товары по разным типам цены; кнопка меняет цену только выбранного товара. Доступно на телефоне и компьютере. Новые товары добавляются по розничной цене.
- Мобильный поиск показывает устойчивый список с кнопкой «В корзину». После добавления открывается корзина. Пустой поиск не выводит каталог.
- Нажатие на фотографию товара открывает крупный просмотр; закрытие крестиком, нажатием снаружи или Esc.
- 3 ноября добавлены инструменты отдельной установки, импорт приватного архива и адрес установки от текущего сайта. Эта подготовка GitHub сама по себе не обновляет исходный сервер.
- Данные новой установки и настройки входа находятся в **`.selfhost-data`**. Папка исключена из Git, её нужно сохранять в личных резервных копиях.
- `pnpm start:local` предназначен для новой установки. Команда `pnpm start` сохранена для прежнего серверного размещения.
- VAG SERVICE PRO — самостоятельный проект, в этот репозиторий не входит.

## Разработка

Исходники интерфейса находятся в `app/` и `components/`, расчётов — в `lib/`. Схема базы — в `drizzle/`. Локальные DB и BUCKET объявлены в `.openai/hosting.json`.

Приложение использует Vinext, React, Wrangler/Miniflare и локальное хранилище D1/R2. Для указанной установки учётная запись Cloudflare не нужна. Файл `pnpm-lock.yaml` фиксирует зависимости. Лицензии сторонних ресурсов находятся рядом с ними в `build/`, `public/` и `vendor/`.
