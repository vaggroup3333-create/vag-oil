# Установка отдельного VAG Oil

Эта инструкция создаёт самостоятельную программу. Касса, товары и отчёты будут храниться на вашем компьютере или сервере. Изменения в копии не передаются в магазин, от которого получена база.

## 1. Подготовить компьютер

Установите:

- [Node.js](https://nodejs.org/en/download) ветки 22, версия не ниже 22.13.
- [Python](https://www.python.org/downloads/) 3.10 или новее. В Windows включите добавление Python в PATH.
- [Git](https://git-scm.com/downloads), если будете загружать код командой `git clone`. Можно также скачать GitHub → Code → Download ZIP и распаковать код.

Установите менеджер зависимостей:

```sh
npm install --global pnpm@11.25.0
```

Все дальнейшие команды выполняются в папке новой копии программы. Для постоянной работы с нескольких устройств удобен отдельный сервер Linux с доменом и HTTPS.

## 2. Скачать и собрать программу

```sh
git clone https://github.com/vaggroup3333-create/vag-oil.git
cd vag-oil
pnpm install --frozen-lockfile
pnpm build
```

Дождитесь завершения каждой команды. Не используйте `pnpm install --prod`: инструменты сборки и локального сервера нужны для этой установки.

## 3. Выбрать свою базу

### Полученная от владельца копия

Получите приватный файл `VAG-Oil-private-database-....zip` лично от владельца. Не загружайте его на публичный GitHub. Положите архив **за пределами папки исходного кода**.

Linux / macOS:

```sh
python3 scripts/setup-instance.py "/полный/путь/VAG-Oil-private-database.zip"
```

Windows PowerShell:

```powershell
py -3 scripts/setup-instance.py "C:\Users\ВашеИмя\Downloads\VAG-Oil-private-database.zip"
```

Замените путь и имя файла на фактические. Архив не нужно распаковывать. Установщик проверит состав и контрольные суммы, загрузит товары, документы, клиентов, долги, остатки и фотографии. Сохраняется именно учёт на момент выгрузки, включая черновики. Неотправленные чеки, хранящиеся только в браузере исходного магазина, в архив не входят.

Версия приложения должна совпадать с `applicationVersion` в `manifest.json` архива. Для копии от 3 ноября 2026 года нужна версия **0.66.5** с этим установщиком. Перед установкой зависимостей и сборкой переключитесь на неё командой `git checkout c6ed9dc30ae56a039d9fd21ff66cc59c87560499`. Не импортируйте копию повторно поверх действующей базы.

### Пустая программа

Если хотите начать собственный учёт с нуля, запустите установщик без пути к архиву:

```sh
python3 scripts/setup-instance.py
```

В Windows: `py -3 scripts/setup-instance.py`.

## 4. Создать доступ

Установщик спросит:

1. **Director login** — новый логин директора, 3–32 латинских буквы, цифры, точка, дефис или подчёркивание.
2. **NEW password** — свой пароль длиной 10–256 символов, затем повтор пароля. При вводе символы не отображаются.
3. **Cashier login** — отдельный логин кассира. Можно нажать Enter, чтобы пока создать только директора. Если логин указан, задайте отдельный пароль кассира.

Пароли исходного магазина и его активные входы не копируются. Программа создаёт нового владельца данных. Дополнительного администратора можно настроить позднее из кабинета директора.

При сообщении **Ready** база и настройки находятся в `.selfhost-data`. Повторный запуск установщика не перезаписывает существующую установку.

Если настройка остановилась, она оставляет отдельную приватную папку `.selfhost-import-...` для диагностики. Не публикуйте её; это может быть частично импортированная база. Исходный архив сохранён без изменений.

## 5. Запустить

```sh
pnpm start:local
```

Оставьте окно запущенным и откройте на этом же компьютере:

- Кабинет: **http://localhost:9088/vag-oil/**
- Касса: **http://localhost:9088/vag-oil/cashier**

Войдите со своим новым логином. Для остановки нажмите Ctrl+C. Для следующего запуска достаточно `pnpm start:local`; снова импортировать базу не нужно.

Если порт 9088 занят, задайте другой, например в PowerShell `$env:VAG_OIL_PORT='9089'`, или в Linux `VAG_OIL_PORT=9089 pnpm start:local`.

## 6. Доступ с телефона или другого ПК

Для сетевого доступа нужен **ваш домен и HTTPS**. Настройте обратный прокси на `127.0.0.1:9088`. Это нужно для защищённого входа, камеры и установки кассы на телефон. Не открывайте порт локального сервера напрямую в интернет.

Пример Caddy для **своего отдельного сервера** после направления домена на него:

```caddyfile
shop.example.com {
    reverse_proxy 127.0.0.1:9088
}
```

Замените `shop.example.com` своим доменом. Прокси должен передавать `X-Forwarded-Host` и `X-Forwarded-Proto`. Внешние страницы: `https://ваш-домен/vag-oil/` и `https://ваш-домен/vag-oil/cashier`.

Для постоянного запуска в Linux можно создать отдельную службу systemd. Пример, если код находится в `/opt/vag-oil-friend`, Node — в `/usr/bin/node`, а программа установлена от отдельного пользователя `vag-oil-friend`:

```ini
[Unit]
Description=VAG Oil independent instance
After=network.target

[Service]
Type=simple
User=vag-oil-friend
WorkingDirectory=/opt/vag-oil-friend
ExecStart=/usr/bin/node /opt/vag-oil-friend/scripts/start-local.mjs
Environment=VAG_OIL_PORT=9088
Restart=on-failure
RestartSec=5
UMask=0077

[Install]
WantedBy=multi-user.target
```

Укажите фактические пути и имя пользователя. Он должен иметь доступ к своей папке программы, `dist/server` и `.selfhost-data`. Настройку службы и HTTPS выполняет администратор вашего сервера. Оригинальный сервер магазина для установки не требуется.

## 7. Резервная копия и обновление

Для полной резервной копии своей установки:

1. Убедитесь, что кассы передали все чеки на сервер.
2. Остановите **свою** службу или окно `pnpm start:local`.
3. Скопируйте целиком `.selfhost-data` в приватное хранилище и сохраните номер версии/комммита исходников. Эта папка содержит данные и настройки входа.
4. Запустите программу снова.

Для восстановления переносите папку целиком в отдельную установку той же версии при остановленной программе. Не запускайте поверх неё `setup-instance.py`.

Перед обновлением сделайте резервную копию. Затем остановите свою программу, загрузите обновлённый код, выполните `pnpm install --frozen-lockfile`, `pnpm build`, снова `pnpm start:local`. Сборка обновляет `dist`, а данные остаются в `.selfhost-data`.
