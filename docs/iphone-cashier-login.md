# Касса на iPhone и Face ID

Откройте `/vag-oil/cashier` на своём HTTPS-сайте в Safari. Если вход ещё действует, касса откроется сразу. При переходе на главную страницу под кассиром приложение также откроет кассу. Для намеренной смены пользователя используйте ссылку «Вход директора» или `/vag-oil/?switch=1`; вход администратора остаётся отдельным.

## Один раз настройте iPhone

1. Войдите личным логином кассира и существующим паролем. Сохраните их, когда Safari предложит. Если предложения нет, добавьте запись для адреса сайта в приложении «Пароли».
2. В настройках iPhone включите автозаполнение паролей. На новых версиях iOS: «Основные» → «Автозаполнение и пароли». Выберите приложение «Пароли» как источник.
3. В разделе «Face ID и код-пароль» разрешите автозаполнение паролей с Face ID. Названия пунктов могут отличаться в зависимости от версии iOS.

## Следующий вход

Нажмите поле логина, выберите сохранённую учётную запись над клавиатурой или через кнопку «Пароли», подтвердите Face ID, затем нажмите «Войти в кассу».

Face ID подтверждает доступ к сохранённому паролю средствами iPhone. Приложение не получает изображение лица и не хранит открытый пароль на устройстве самостоятельно. Это автозаполнение существующего пароля, а не отдельный вход по ключу доступа (passkey). При действующей сессии повторный ввод не нужен; срок сессии и правила отключения кассиров не меняются.

Кнопка «Выход» завершает сеанс, но не удаляет пароль, сохранённый в iPhone. Если нужно только закрыть кассу, закройте вкладку. В Safari и в отдельном приложении с домашнего экрана может потребоваться отдельный первый вход.

Справка Apple: [Автозаполнение паролей](https://support.apple.com/en-ie/guide/iphone/-iphf9219d8c9/ios), [Password AutoFill](https://developer.apple.com/documentation/Security/password-autofill).
